# Newsfall Implementation Plan

> **For agentic workers:** Execute test-first in an isolated feature branch.

**Goal:** Build a colorful, continuously refreshing, configurable terminal feed with responsive TweetDeck and stream modes.

**Architecture:** A zero-dependency Go application separates config, content normalization, feed ingestion, cache, commands, ANSI rendering, and the raw-terminal event loop. Runtime state is local; network and image work returns through channels.

**Tech Stack:** Go 1.23 standard library only.

**Spec:** `docs/superpowers/specs/2026-09-02-newsfall-design.md`

## Tasks

1. Build and test the article/config model with atomic JSON persistence.
2. Build and test remote-text cleanup, matching, assignment, and deduplication.
3. Build and test RSS/Atom/JSON Feed ingestion and the offline cache.
4. Build and test shell-like commands and configuration mutation.
5. Build and test responsive ANSI layout, themes, cards, mosaics, and snapshots.
6. Build the raw-terminal event loop, browser integration, image loading, CLI, documentation, and release binaries; then run format, vet, race tests, smoke tests, and cross-compilation.
